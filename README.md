# Murad's Salon Website

A responsive one-page website for Murad's Salon.

## Files
- `index.html`
- `styles.css`
- `script.js`

## Before publishing
Replace the placeholder `#` links for:
1. Online booking
2. Google reviews
3. Google Maps

Also update the exact street address if required.

## How to preview
Open `index.html` in a web browser.

## How to publish
This website can be uploaded to:
- Vercel
- Netlify
- Hostinger
- cPanel hosting
- GitHub Pages
